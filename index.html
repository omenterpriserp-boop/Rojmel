Google Drive Backup ☁️

Mail ID se login karo, data aapki Drive me safe rahega

Client ID kaise banayein? (steps)
  1. Google Cloud Console (console.cloud.google.com) kholo, free me naya project banao
  2. APIs & Services me Google Drive API enable karo
  3. OAuth consent screen me External select karke apna email daalo
  4. Credentials → Create Credentials → OAuth client ID → Web application
  5. Authorized JavaScript origins me apni website ka address daalo (jaise https://aapka-naam.github.io)
  6. Bani hui Client ID copy karke upar paste karo aur save karo

Note: Google login ke liye is file ko internet pe host karna padega (jaise GitHub Pages, bilkul free). Bina hosting ke login kaam nahi karega.

Abhi tak koi backup nahi hua.
